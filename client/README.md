# Independent Approval

Stage 1 front-end shell for an independent, on-premises approval management application.

## Included

- Responsive desktop, tablet, and mobile application layout
- Collapsible navigation and mobile menu
- Dashboard with request, task, and document summaries
- Request, task, document library, and administration workspaces
- Typed local mock data and a synchronous mock service facade
- English left-to-right presentation with logical CSS properties for future Arabic RTL support

## Development

```sh
npm run dev
```

## Validation

```sh
npm run build
npm run lint
```

Stage 1 is front-end only. It does not make backend or API calls.
